# Монополия (Monopoly)

Минимальный, но полностью компилируемый каркас игры «Монополия» на Godot 4
для сборки под Android. Godot распространяется под свободной лицензией и не
требует Unity-активации, лицензионных файлов или платных секретов CI.

## Структура проекта

```
icon.png                   — иконка приложения (свинья-копилка в цилиндре)
project.godot              — настройки Godot и точка входа
main.tscn                  — основная сцена
scripts/main.gd            — стартовый экран, игровой цикл, правила, ИИ, сохранение
scripts/board_view.gd      — отрисовка классического поля 11x11 и персонажей
scripts/dice_view.gd       — отрисовка игральных кубиков
Assets/icons/              — Android launcher icons (адаптивные)
export_presets.cfg         — бесплатный Android export preset
.github/workflows/build-android.yml — CI-сборка APK через Godot
```

## Игра

- **Стартовый экран** — выбор одной из четырёх игр: «Классика» (московские
  улицы), «Звёздные Войны», «Рик и Морти», «Аниме-клуб». У каждой своя
  палитра, названия клеток, валюта и подписи.
- **Поле 40 клеток** по официальным правилам Монополии: 22 улицы восьми
  цветовых групп, 4 железные дороги, 2 коммунальных предприятия, 3 «Шанс»,
  3 «Общественная казна», 2 налога, СТАРТ, Тюрьма, Бесплатная парковка и
  «Отправляйтесь в тюрьму».
- **Правила**: стартовый капитал 1500, зарплата 200 за проход СТАРТа, дубли
  дают дополнительный бросок (три подряд — тюрьма), выход из тюрьмы дублем
  или штрафом 50, аренда удваивается при монополии на цветовую группу, аренда
  ж/д растёт от числа станций у владельца, коммунальные предприятия берут
  плату по кубикам.
- Фишки игроков — нарисованные свиньи-копилки в цилиндрах (маскот игры).
- Сохранение создаётся в `user://monopoly_save.json`, что работает на Android
  без дополнительных разрешений.

## Требования

- Godot **4.3 или новее**.
- Android SDK/шаблоны экспорта Godot для локальной сборки.
- Внешние зависимости и секреты не требуются.

## Сборка под Android

### Локально

1. Откройте папку проекта в Godot.
2. Запустите сцену `main.tscn`.
3. Для Android установите export templates и выберите пресет `Android`.

### Через GitHub Actions

Сборка автоматизирована в `.github/workflows/build-android.yml` в контейнере
Godot CI. Никакие GitHub Secrets не нужны.

Готовый APK публикуется как артефакт `android-build`. CI экспортирует
отладочную, подписанную APK, поэтому её можно установить на устройство.

## Расширение проекта

- **Новая тема**: добавьте запись в словарь `THEMES` в `scripts/main.gd` —
  палитру, названия 20 улиц, 4 станций, 2 коммунальных и 2 налоговых клеток.
- **Новая механика**: добавьте обработку в `after_move`/`_apply_card` в
  `scripts/main.gd`.
- **Отрисовка поля**: `scripts/board_view.gd` рисует доску средствами Godot 2D
  (цветные полосы групп, иконки клеток, фишки-персонажи).
